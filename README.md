관리폰은 홈·태블릿·전체로 정리했습니다. 홈에서 기기·알람·타이머·F1·집 위치를 열고, 세부 설정은 집·생활·음성·화면으로 나눕니다. 연결 복구와 오류 진단은 전체 메뉴에 있습니다.

집 위치는 지역 검색이나 한 번의 현재 위치 확인 후 직접 선택·저장합니다. 등록된 태블릿과 휴대폰의 날씨에 반영하며 지속 위치 추적은 하지 않습니다.

태블릿은 둥근 서체와 색상 카드, 선택 메뉴의 유리 효과를 적용했습니다. 기본 F1 사진 3장 또는 직접 고른 사진 최대 12장이 부드럽게 바뀝니다. 메뉴에서 10초 미사용하면 사진 시계로 돌아옵니다.

**헤이, 서버** 호출은 빠른 메뉴 → 설정 → 호출어 설정에서 한국어 인식 파일을 받은 뒤 켭니다. 세 번 말하는 발음 보정을 제공하며 화자 인증이나 새 모델 학습은 아닙니다. 인식 파일이 준비된 태블릿은 앱 내 음성 인식과 F1 라디오 시작·종료 효과음을 사용합니다. 시스템 인식으로 전환한 경우 F1 효과음을 함께 재생하지 않습니다.

PC 없이 기본 홈 제어·날씨·검색·F1·YouTube 명령을 사용할 수 있습니다. **자유 대화용 클라우드 LLM은 이번 버전에 연결하지 않았고, 유료 AI 키·선불 잔액을 자동 사용하지 않습니다.** Google Home은 각 앱의 설정에서 본인 계정과 집 접근을 직접 허용하세요. 지원되는 실제 기기를 표시하며 기기별로 가능한 조작만 제공합니다.

F1 라이브 순위는 현재 세션의 새 데이터가 수신되는 동안만 표시합니다. 종료·수신 지연·연결 해제 시 일반 일정·순위·최근 결과로 돌아갑니다. 항상 실시간 제공을 보장하지 않습니다.

알람·타이머는 관리폰에서 연결된 태블릿의 설정을 바꿀 수 있습니다. 알람은 선택한 소리의 알림 방식이며 반복 울림·전체 화면 알람 시계와 Google Home 조명 기상 예약은 포함하지 않습니다.

이후 새 버전은 앱에서 자동 안내하고 앱 안에서 다운로드합니다. 최종 설치 확인은 Android에서 허용해야 합니다. 백그라운드 알림은 절전·네트워크 상태에 따라 늦을 수 있습니다.
